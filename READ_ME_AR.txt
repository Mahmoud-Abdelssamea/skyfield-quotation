تحديث الحد الأدنى لكود الموظف وكلمة المرور

الكود: أرقام إنجليزية فقط (0–9)، من 6 إلى 40 رقمًا.
كلمة المرور: أرقام إنجليزية فقط (0–9)، 6 أرقام أو أكثر، وليست 6 بالضبط.
كلاهما يقبل الصفر في البداية. كلمات المرور الحالية وأكواد الحسابات الموجودة لا تتغير تلقائيًا.
شرط الكود يطبق عند إنشاء الحساب الجديد، وشرط كلمة المرور عند الإنشاء أو إعادة التعيين.

استخدم هذه الحزمة بدل حزمة الـ6 أرقام بالضبط السابقة:
1. ارفع واستبدل attendance.js وattendance-module.html على GitHub ثم Commit changes.
2. Supabase → Edge Functions → rapid-task → Code: استبدل الكود كله بمحتوى rapid-task.ts ثم Deploy.
3. في إعدادات كلمات المرور في Supabase، تأكد أن Minimum password length = 6، بدون اشتراط حروف أو رموز. إذا ضبطتها بالفعل فلا تحتاج تغييرها.
4. بعد نشر الموقع اضغط Ctrl + F5.
لا تحتاج SQL أو إعادة رفع باقي الملفات. ملف rapid-task.ts يوضع في Supabase وليس GitHub.
لم يتم النشر أو تعديل إعدادات Supabase من هنا.
